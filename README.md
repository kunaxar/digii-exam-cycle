# Exam Cycle

Working fictional university exam-process prototype for the Digii APM assignment.

## Run
Node18+ required. `npm ci`, `npm test`, `npm run build`. Open the generated `dist/index.html` or serve the dist directory. React is bundled locally; no login or real payment required.

## Evaluate
Start empty, enter institution/semester and review defaults. Activate1 November event, advance to5 November, switch throughS01/S02/S06/S07. Select intended papers and submit/pay as each rule permits. Advance each dated timeline event, inspect impact then approve with a reason. The explicit Load due case facts button imports the supplied historical payments/draft only when their date is reached. Preview is not confirmation. Moving date does not silently execute policies.

Use Reviews & finance for condonation, tuition clearance, bank reconciliation or an audited paper amendment. On5 December publish the authorised student-paper roster. Its counts feed seats and printing. On6 December applyS09's correction, inspect active snapshot and ticket revision.

## Assumptions
Overall attendance, exact75% threshold, program-limited condonation. Tuition dues block clearance. C-grade improvement allowed. Settled extra-paper rates protected; late fee on registrations14-20 November. Payment initiation controls timeliness.26 November remedial window after cut-off movement. October correction does not invent an updated November snapshot. Refunds require finance review. Owners are simulated by role switch.

## Scope
All12 students and facts are fictional. Simulated payment, notification, owner authority and attendance integrations. Local browser storage only, no shared backend. Reset returns to empty semester setup. No real money moves. No production security is implied.
